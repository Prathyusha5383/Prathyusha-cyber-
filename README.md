# Cybersecurity Asset Inventory System

## Description
A Python-based system for managing an organization's IT assets.

## Features
- Add Asset
- Search Asset
- Update Asset
- Delete Asset
- Display Assets
- Display Statistics

## Asset Types
- Workstation
- Server
- Router
- Switch
- Application

## Risk Levels
- Low
- Medium
- High
- Critical

## Security Status
- Secure
- Warning
- Vulnerable

## Programming Language
Python
